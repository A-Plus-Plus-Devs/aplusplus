# Hello World Example

The classic first program in A++.

## Basic Example

```a++
fn main() {
    print("Hello, World!")
}
```

## Explanation

This simple program demonstrates:
- The main function structure
- Basic print statement
- String literals

## Running the Program

Save this code in a file with `.a++` extension and run it using the A++ compiler:

```bash
a++ hello.a++
```
